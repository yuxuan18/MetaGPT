
# Running MetaGPT for Exploiting Zero-day Vulnerabilities

In this repository, we show the scripts, execution logs, and execution 
results of MetaGPT on a zero-day vulnerability benchmark used by HPTSA. We 
forked the official GitHub repository of MetaGPT and provide:

1. `run.py`: the script we used to run MetaGPT
2. `logs/20250328.txt`: the execution logs
3. `results/CVE-2024-*`: the results of running MetaGPT.
